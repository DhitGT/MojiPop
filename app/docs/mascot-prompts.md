## Revisi aktif: tanpa buku dan kedipan

Keempat maskot diedit memakai built-in `image_gen`, dengan PNG masing-masing sebagai edit target. Hasil berupa strip transparan dua frame (1774 × 887), dipisah tepat di tengah tanpa menggambar ulang. Frame terbuka menggantikan `public/images/{id}-mascot.png`; frame mata tertutup disimpan di `public/images/{id}-blink.png`, untuk `id` = `kiko`, `mimi`, `kuro`, `momo`. Alpha asli dipertahankan. Semua karakter sekarang bertangan kosong. Prompt sebelumnya di bawah adalah riwayat produksi.

Prompt yang dipakai per karakter (ganti `{id}` dengan identitasnya):

> Use case: precise-object-edit. Edit target: the provided {id} mascot. Create a transparent animation strip, exactly TWO equally sized SQUARE cells side-by-side, total canvas aspect ratio 2:1. This is a production sprite strip, not a comparison graphic. BOTH cells contain precisely the SAME full-body cat, SAME registration, SAME size, SAME pose, SAME head and fur markings, same centered framing, generous matching transparent margin. Left cell: eyes open, exactly matching the input character's face and expression. Right cell: identical except BOTH eyes naturally CLOSED for a blink, curved dark eyelid lines in place of open eyes. PRIMARY CHANGE IN BOTH FRAMES: completely REMOVE the purple BOOK and all held objects, reconstruct the belly naturally and give the cat two empty relaxed paws, a natural relaxed seated stance. Preserve the original character identity, head size/placement, original face, ear positions, fur colors, proportions, thick navy outlines, polished shaded game-sticker style, and curled tail. If input paw waves, retain its raised empty paw and pose; remove only the book from the other paw. Do not add props, labels, motion marks, lettering, captions, panel borders, background, shadows outside cat, logos, or watermark. Actual alpha transparency. Exactly two cells: open eyes left, blink right. Frames must align pixel-perfectly for smooth blinking; no body motion or shifting between frames.

`KikoMascot.vue` menumpuk dua frame sesuai ukuran container. `TypingRaceMascot.vue` memakai pasangan frame yang sama di kepala SVG. Animasi CSS bersama di `assets/css/mascots.css` memberi kedip singkat dan kedip ganda dengan tempo berbeda per karakter. Reduced motion menampilkan mata terbuka, tanpa animasi. Interaksi sapaan dan gerak idle tetap aktif pada pengaturan normal.

Dibuat dengan built-in `image_gen` (bukan CLI). Keduanya PNG dengan alpha transparan, disalin ke workspace tanpa mengubah aset asli. Foto pengguna dipakai sebagai referensi identitas, Kiko sebagai referensi gaya. File final:

## Kuro

Use case: illustration-story. Create ONE new transparent PNG mascot asset for KanaLearn. Reference roles: attached photograph of BLACK cat is identity reference; attached white cat photo is NOT this character; turquoise illustrated cat Kiko is STYLE AND COMPOSITION reference only. Character name Kuro: solid charcoal-black cat, olive-yellow eyes, upright ears, deadpan slightly unimpressed sly expression with tiny one-sided smile. Preserve the black photo cat's recognizable appearance. Match Kiko's bold navy outlines, clean flat colors and gentle cel shading, cute large head small full body, polished game sticker. Pose front facing exactly like Kiko: huge head in upper 60%, ears fully within square, small seated body, both paws lowered holding a small purple closed book near belly, long curled black tail. No waving paw, no motion marks. Full square composition, entire body visible, transparent alpha, no background, text, lettering, logos, or watermark. Keep eye centers around 36% and 68% width, at 39% and 42% image height, so runtime eyelid overlays align. Head cheek extends from x20% to x85%, chin around y62%. Generate only Kuro, not multiple cats.
